PRINTER TERMAL (ESC/POS)
• Printer Windows (QZ Tray): cara paling cocok jika printer thermal sudah terpasang di Windows. Cetak langsung tanpa preview. Perlu memasang aplikasi gratis QZ Tray (qz.io) di komputer ini dan menjalankannya. Saat browser/QZ meminta izin, pilih Allow dan centang Remember.
• Gunakan Chrome atau Edge (desktop / Android). Izin printer tersimpan, jadi setelah halaman dibuka ulang printer terhubung otomatis.
• USB: di Windows, printer harus memakai driver WinUSB (bisa dipasang dengan aplikasi Zadig). Jika tidak, pakai Serial.
• Serial / Bluetooth: untuk printer dengan port COM (USB-serial atau Bluetooth yang sudah dipasangkan di Windows/Android).
• Jika printer tidak terhubung atau gagal, cetak otomatis memakai dialog cetak browser.
